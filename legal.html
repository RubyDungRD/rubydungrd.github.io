Relationship to Minecraft

RubyDung began as a source-level fork of an early, historical version of Minecraft, used as an engineering starting point for the ground-up development of a separate, original piece of software.

Development currently makes use of some assets originally created for Minecraft. These are not redistributed by this project in any public build or release. No compiled build intended for general public use will be published until these assets are fully replaced with original work — this replacement is an active, ongoing part of the project's development plan. Building the project from source is possible via the GitHub repository; doing so does not involve this project distributing any Minecraft assets, and anyone building from source who supplies their own copies of any such assets is doing so on their own account.

RubyDung is not a substitute for, or a redistribution of, Minecraft. Any resemblance present in current development builds reflects this project's shared starting point, not an intent to imitate or replace the original game.
