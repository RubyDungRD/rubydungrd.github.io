What is RubyDung?

RubyDung is an independent open-source software project that begins with Minecraft 1.5.2 as a foundation and gradually rebuilds nearly every part of it.

The long-term goal is to modernize the engine, rendering, architecture, build tooling, programming language, and modding support, while eventually becoming its own independent voxel sandbox.

RubyDung is not a Minecraft mod, a client, a server plugin, or a launcher. It is its own codebase with its own build system, its own architecture, and its own future.

Why 1.5.2?

Minecraft 1.5.2 (the Redstone Update) represents a unique point in the game's history. It is old enough to be relatively simple and comprehensible as a codebase, yet modern enough to contain the core systems that define the game: the full block engine, item system, redstone, entities, world saving, and multiplayer.

Starting from 1.5.2 gives us a complete, working game that we can understand in its entirety. There is no mystery code, no obfuscated legacy systems we cannot touch. Every line can be read, understood, and eventually replaced.

Later versions of Minecraft grew increasingly complex, with thousands of classes and deeply entangled systems. 1.5.2 is the sweet spot: complex enough to be interesting, simple enough to be tractable.

The Philosophy

RubyDung follows a gradual replacement strategy rather than a rewrite. A complete rewrite of a codebase this size would take years before producing anything runnable. Instead, we replace components one at a time, always keeping the project in a working state.

This approach has several advantages:

  • The project is always runnable and testable.
  • Each replacement can be validated independently.
  • We learn from the original code rather than repeating its mistakes.
  • Progress is visible and measurable at every step.

We prioritize understanding over speed. The goal is not to produce a Minecraft clone as quickly as possible, but to build something better, piece by piece, with full understanding of each component.

The Ship of Theseus

RubyDung is a Ship of Theseus project. We start with the original Minecraft 1.5.2 codebase and gradually replace every component until nothing of the original remains.

At each step, the project remains a working game. The question of when it stops being "Minecraft with modifications" and becomes "RubyDung" is philosophical rather than technical. What matters is the process: understanding, improving, and eventually transcending the original.

When the last line of original code is replaced, RubyDung will be something entirely its own. But the journey matters as much as the destination.

Long-Term Goals

  • Engine Modernization — Replace the legacy rendering pipeline with a modern architecture. LWJGL migration, shader-based rendering, and eventually a custom renderer.
  • Kotlin Migration — Gradually migrate the codebase from Java to Kotlin, taking advantage of modern language features while maintaining interoperability with existing Java code.
  • Modding API — Design a proper modding API inspired by the best ideas from Forge, Fabric, Bukkit, and the community. First-class support, stable APIs, and clear documentation.
  • Original Assets — Replace all original Minecraft assets with original artwork, sound, and music. RubyDung will stand on its own visually and audibly.
  • Architecture — Clean separation of concerns. Client and server properly decoupled. Systems designed for testability and maintainability.
